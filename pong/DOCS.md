# Pong samen

Open de webinterface vanuit Home Assistant of via `http://<home-assistant-adres>:8096`. Voor een uitnodiging naar iemand zonder Home Assistant-account start je de lobby via het directe adres en deel je de link of lobbycode.

De directe poort is toegankelijk voor apparaten die de server kunnen bereiken en gebruikt geen Home Assistant-login. Scherm deze af als dat nodig is. Via Ingress geldt de toegang van Home Assistant.

Gebruik de muis, pijltjestoetsen, W/S of een aanraakscherm om te spelen. De eerste tot zeven punten wint. Als de host vertrekt, sluit de lobby. Er worden geen bestanden of persoonsgegevens opgeslagen; actieve potjes verdwijnen wanneer de addon herstart.
